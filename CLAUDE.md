# Working on this site with Claude Code

Jekyll site (academicpages / Minimal Mistakes), deployed by GitHub Pages from `master`.

## Rules
- Do not write site content (prose, summaries, bios, substantive headings, typo fixes) unless asked.
  Put `<!-- TEXT: ... -->` placeholders where text is needed; insert the owner's text verbatim.
- Do not invent facts (dates, roles, names, URLs, DOIs). Ask.
- Never modify `files/publications/*.pdf`.
- Work on the `dev` branch and push it to `origin/dev`. Merge into `master` (which deploys the live site)
  only when the owner says so.
- Small, logically separate commits; get the owner's approval before each commit.
- Build and link-check locally before committing.

## Setup (Linux)
```
sudo apt install ruby-full build-essential
gem install --user-install bundler html-proofer
export PATH="$(ruby -e 'print Gem.user_dir')/bin:$PATH"
bundle config set --local path vendor/bundle
bundle install
sudo apt install texlive-xetex texlive-latex-extra texlive-science texlive-fonts-extra   # CV PDF
```
In the VS Code snap, `Gem.user_dir` points inside the snap: use
`export GEM_HOME=~/.local/share/gem/ruby/3.0.0 PATH=~/.local/share/gem/ruby/3.0.0/bin:$PATH` instead.

## Build and check
```
bundle exec jekyll serve          # http://127.0.0.1:4000
bundle exec jekyll build
htmlproofer _site --disable-external --checks Links,Images,Scripts \
  --swap-urls '^https\://flblanc.github.io:' \
  --ignore-files '/_site\/(markdown_generator|tools|CONTRIBUTING)/'
```
Drop `--disable-external` for a full check. 403s from doi.org/publishers, ResearchGate and LinkedIn (999)
are bot-blocking; the fonts.googleapis/gstatic 404s are preconnect false positives.

## Where things live
- Publications: `_publications/*.md` are generated by `tools/build_publications.py` from
  `_bibliography/MyPublications.bib` + `_data/pub_extras.yml`; a GitHub Action regenerates them on push.
  Edit the .bib or `pub_extras.yml`, never `_publications/`. Pull before editing: the Action commits back.
- Team: one file per person in `_team/` (template: `_team/_template.md`), rendered on `/team/` and in
  the CV's Supervision section via `_includes/team-compact.html`.
- Teaching: `_teaching/` (one file per course, with its own detail page), rendered in the web CV's Teaching
  section and, via `tools/build_cv.py`, in the PDF; `dates`, `items` (role bullets) and `title_en` are shown
  in both. `/teaching/` redirects to `/cv/#teaching`.
- Talks: `_data/talks.yml` (invited, oral, poster), rendered on `/talks/` (not in the menu), in the web CV's
  Invited talks, and in the PDF's Communications section.
- CV: `_data/cv/*.yml` is the single source for sections shared by the web CV (`_pages/cv.md`, Liquid)
  and the PDF (`tools/build_cv.py` writes git-ignored `cv/generated/*.tex`). Layout and the remaining
  hand-written sections are LaTeX in `cv/` (Awesome-CV, XeLaTeX; excluded from Jekyll). The "Build CV PDF"
  Action generates, compiles and commits `files/FlorianBlanc_CV.pdf`; do not commit that PDF by hand.
  Local check: `python3 tools/build_cv.py && (cd cv && xelatex resume.tex)` (output `cv/resume.pdf`, ignored).
  The PDF's publication list is generated from `_publications/*.md` (same source as the website), with the
  trainee legend from `_pages/publications.md`.
- Rare Events (personal blog): sources are Obsidian notes in `_notes/*.md` (front matter as Properties; templates
  in `_notes/_templates/`) and the shared `_notes/blog-posts.bib`. `tools/obsidian2post.py` (run locally, and by the
  "Rare Events posts" Action on push) writes `_drafts/slug.md`, or `_posts/DATE-slug.md` when the note has
  `publish: true` + `date`; generated files carry `source_note:` and are never edited by hand (pull before editing:
  the Action commits back). Conversion: wiki-links → plain text, citekeys → numbered citations + `## References`,
  inline `$x$` → `$$x$$`. Layout `_layouts/post.html` (`kind: essay | book-notes`, `disclaimer`, book fields), URLs
  `/rare-events/:year/:title/`; preview drafts with `jekyll serve --drafts`. Index `_pages/rare-events.md`, tags
  `_pages/rare-events-tags.md`; nav entry commented out until launch. Keep posts off professional pages. Posts in
  `_posts/` go into `feed.xml`: the owner has not yet decided whether they should (ask before the first publish).
- Navigation: `_data/navigation.yml`. Sidebar: `author:` block in `_config.yml`.
